# assets

## Música de fondo (opcional)

El juego usa música **lofi procedural** generada con Web Audio API, así no depende
de ningún archivo externo ni de copyright.

Si querés usar el track real (el de YouTube `1DVfpDtrCew`), bajalo a mp3 y guardalo
acá como:

```
assets/track.mp3
```

El juego lo detecta automáticamente al cargar y lo reproduce en loop cuando arrancás
a hablar con el FRU MAN. Si el archivo no existe, cae de nuevo en la música procedural.

> Nota: descargar audio de YouTube puede infringir sus términos / derechos de autor.
> Usá solo material sobre el que tengas derechos.
